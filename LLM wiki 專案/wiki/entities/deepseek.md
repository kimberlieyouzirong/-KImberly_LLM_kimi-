# DeepSeek (深度求索)

## 基本資訊
- **類型**：AI 研究機構 / 科技公司
- **成立背景**：由量化基金幻方量化（High-Flyer）孵化創立
- **研究重點**：開源大規模語言模型、高能效架構創新（MLA、DeepSeekMoE）、強化學習推理模型

## 代表性成就與模型系列
1. **DeepSeek-LLM / DeepSeek-Coder**：奠定早期開源代碼與對話能力基礎。
2. **DeepSeek-V2 / V3**：提出多頭潛在注意力機制 (Multi-head Latent Attention, MLA) 與細粒度專家混合 (DeepSeekMoE)，將訓練與推理推向極致成本效益。
3. **[[deepseek-r1|DeepSeek-R1]] 系列**：探索以純強化學習 (Large-scale RL) 激發大模型自我推理與思維鏈能力，成為全球開源推理模型的指標標竿。
